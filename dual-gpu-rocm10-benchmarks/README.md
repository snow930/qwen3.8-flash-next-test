# X99 平台双 AMD 显卡（RX 7900 XT + RX 6800 XT）ROCm 10.1.0 异构联合推理评测报告

本项目针对 **AMD ROCm 10.1.0** 最新环境下，采用 **异构双卡（RDNA 3 + RDNA 2）** 运行 **Qwen3.8-Flash-Next (IQ3_XXS)** 模型的推理性能、显存扩展效果、内存频率敏感度与整机峰值功耗进行全方位基准评测。

---

## 二、双卡异构协同机制与架构设计

两张显卡为非对称架构（RDNA 3 与 RDNA 2），Strata 采用 **Helper Expert Cache（辅助专家缓存）** 方案进行拓扑协同：
1. **主卡 (RX 7900 XT, 20GB)**：
   - 承载骨干层 Dense 权重、KV Cache 显存驻留池（32k Resident）、Prefill 矩阵加速以及 MTP 投机头；
   - 容纳 7,189 个最高频访问的热门 MoE 专家。
2. **辅卡 (RX 6800 XT, 16GB)**：
   - 挂载为独立计算上下文，承载 **9,523 个次高频专家**（独占 15.1 GB VRAM）；
   - 在 Decode 阶段与主卡重叠发射内核，计算结果经固定主机缓冲区聚合回传。
3. **两卡合计锁定 16,712 个专家常驻物理显存**，专家缓存命中率从单卡的 ~90% 跃升至 **97.6% ~ 98.0%**，几乎完全消除了向主机内存回退的 PCIe 瓶颈。

## 三、基准测试一：单卡 (7900 XT) vs 双卡 (7900 XT + 6800 XT)

> 度量原则：直接从 Strata 底层日志抓取硬件计数器，杜绝客户端壁钟误差；所有场景均进行 3 轮独立采样并取中位数。

### 1. 核心性能对比总览

| 评测场景 | 单卡 (7900 XT 20GB) | 双卡协同 (7900 XT + 6800 XT) | 变化幅度 | 核心收益说明 |
| :--- | :--- | :--- | :--- | :--- |
| **短提示词 解码速度** | 47.40 tok/s `[42.7, 47.4, 50.2]` | **54.50 tok/s** `[51.9, 55.6, 54.5]` | 🚀 **+14.98%** | 稳固站上 55 tok/s，响应更流畅 |
| **专家显存命中率** | 90.1% | **97.6%** (峰值达 **98.0%**) | 🎯 **+7.5%** | 几乎完全告别 CPU/主机内存回退 |
| **8k 上下文 解码速度** | 50.3 tok/s | **73.6 tok/s** `[67.5, 73.6, 79.2]` | 🚀 **+46.32%** | **爆发式提速，彻底释放瓶颈** |
| **32k 上下文 解码速度** | 66.4 tok/s | **71.2 tok/s** `[71.2, 69.9, 79.1]` | 🚀 **+7.23%** | 稳步提升 |
| **48k 上下文 解码速度** | 67.0 tok/s | **77.8 tok/s** `[77.8, 74.1, 81.0]` | 🚀 **+16.12%** | **单次最高冲上 81.0 tok/s** |

| **多轮对话次轮 解码速度** | 52.0 tok/s | **78.1 tok/s** | 🚀 **+50.19%** | 日常对话体感提升显著 |
| **长文本冷 Prefill 吞吐** | ~1,210 tok/s | ~835 tok/s | 📉 **-31.0%** | PCIe 双卡同步协议固定开销 |
| **前缀快取重用率** | 98.06% (880 ms) | 98.06% (1,338 ms) | ⚡ 极高重用 | 极速响应 |

## 四、基准测试二：双卡下内存频率 1867 MT/s vs 1600 MT/s 对比

为探究双卡模式下主机系统内存带宽对整体推理性能的实际影响，在同一双卡环境中将 DDR3 内存频率分别配置为 **1867 MT/s** 与 **1600 MT/s**（严格保持 CPU 锁定在最高 Performance 调频）：

### 1. 实测指标对比表

| 评测维度 | 1867 MT/s 双卡实测 | 1600 MT/s 双卡实测 | 差异幅度 | 结论 |
| :--- | :--- | :--- | :--- | :--- |
| **短提示词 解码中位数** | **54.50 tok/s** `[51.9, 55.6, 54.5]` | **57.30 tok/s** `[51.9, 57.3, 58.2]` | **+5.14%** | 无任何负面影响 (正常统计波动) |
| **8k 梯度 Prefill 吞吐** | **831.1 tok/s** | **829.7 tok/s** | **-0.17%** | 曲线完全重合 |
| **32k 梯度 Prefill 吞吐** | **837.2 tok/s** | **846.2 tok/s** | **+1.08%** | 曲线完全重合 |
| **48k 梯度 Prefill 吞吐** | **843.9 tok/s** | **846.1 tok/s** | **+0.26%** | 曲线完全重合 |
| **80k 梯度 Prefill 吞吐** | **823.9 tok/s** | **807.7 tok/s** | **-1.97%** | 差异小于 2% |
| **8k 梯度 解码速度** | **73.6 tok/s** | **77.1 tok/s** | **+4.76%** | 保持 ~75 tok/s 高位 |
| **32k 梯度 解码速度** | **71.2 tok/s** | **76.7 tok/s** | **+7.72%** | 保持 ~75 tok/s 高位 |
| **48k 梯度 解码速度** | **77.8 tok/s** | **69.8 tok/s** | **-10.28%** | 70 ~ 78 tok/s 震荡 |
| **80k 梯度 解码速度** | **69.6 tok/s** | **80.3 tok/s** | **+15.37%** | 峰值达 80.3 tok/s |

### 2. 结论分析
在双卡将专家显存命中率拉升至 **98%** 之后，系统内存的物理带宽（1867 的 59.7 GB/s 对比 1600 的 51.2 GB/s）不再构成任何解码或预填充的瓶颈。**用户可完全安心将内存工作在更稳妥、发热更低的 1600 MT/s 状态下**。

## 五、基准测试三：实时动态功耗监测

通过硬件级驱动传感器（hwmon `power1_average`）以 80ms 采样周期监测大模型实际高负载运行时的功耗分布：

| 监测项 | RX 7900 XT (主卡) | RX 6800 XT (辅卡) | 双卡瞬间合计 |
| :--- | :--- | :--- | :--- |
| **空闲待机功耗** | ~15.0 W | ~8.0 W | **~23.0 W** |
| **推理平均功耗** | 228.6 W | 20.0 W | **248.5 W** |
| **实测峰值功耗 (Peak)** | **328.0 W** | **69.0 W** | 🔥 **354.0 W** |
| **硬件功耗墙安全上限** | 290 W (BIOS Max 333W) | 239 W (BIOS Max 293W) | **529 W** |

- **功耗倾斜极具优势**：辅助卡 RX 6800 XT 虽然提供了 15.1 GB 显存，但因只做稀疏专家计算，工作平均功耗仅 20W、峰值 69W；
- 整机双卡推理时的实际峰值功耗仅为 **354 W**，供电裕量非常充沛。
